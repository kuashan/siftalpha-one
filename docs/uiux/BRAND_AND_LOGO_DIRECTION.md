# SiftAlpha Brand + Logo Direction（品牌与标志方向）

## Brand Hierarchy（品牌层级）
**SiftAlpha 是主品牌。**

X 的定位是 SiftAlpha 内部的 System / Architecture（系统 / 架构）语义，不是面向普通用户的第二品牌，也不应该与 SiftAlpha 在视觉上并列竞争。

Normal Mode（普通用户模式）默认规则：
- App Icon（应用图标）只表达 SiftAlpha。
- Wordmark（品牌字标）只显示 **SiftAlpha**。
- Home（首页）、Splash / Brand Transition（启动 / 品牌过渡）不突出 X。
- X 仅在 Developer Mode（开发者模式）、Architecture（架构）、About / Diagnostics（关于 / 诊断）等必要场景出现。

## Preserve From Current Logo（保留现有标志资产）
现有 Logo（标志）的最大识别资产是一个清楚、连续、带折叠感的 **S**。

这次不是抛弃现有 Logo（标志），而是对它做 Brand Refinement（品牌精修）：
1. 保留“流动 / 折叠 / 收敛”的 S 轮廓。
2. 提高 S 的第一眼识别度。
3. 去掉任何为了表现 X 而破坏 S 轮廓的结构。
4. 保留现有蓝 → 青 → 紫的科技感，但降低过度霓虹和装饰性渐变。
5. 深色圆角方形底可以继续使用，但需要为 Android Adaptive Icon（安卓自适应图标）和 Monochrome Icon（单色图标）建立独立版本。

## Logo Concept — S Mark（S 标志）
正式主方向：**S Mark（S 标志）**。

### Geometry（几何结构）
- 主体必须首先被读成一个大写 **S**。
- S 可以由两条或三条连续 ribbon（带状）路径折叠形成，表达：
  - Sift（筛选）
  - Flow（流动）
  - Convergence（收敛）
  - Result（结果）
- 结构应在 24–32px 小尺寸仍然清楚。
- 不再把中央交叉结构设计成 X。
- 不把漏斗、K 线、Python 标志、终端符号机械拼接成 Logo（标志）。

### Terminal Motif（终端符号）
现有 >_ 具有“可执行 / 工具”的历史识别度，可以保留为 **secondary motif（次级符号）**，但必须弱化：
- 不作为品牌主体。
- 不压住 S 的连续轮廓。
- 小尺寸 App Icon（应用图标）中可以省略。
- Developer Mode（开发者模式）或启动动画的短暂细节中可以出现。

## Color（颜色）
核心颜色沿用现有识别感，但做更克制的系统化：
- Sift Blue（筛选蓝）: #4F46E5 / dark #7C8DFF
- Signal Cyan（信号青）: #38BDF8
- Sift Violet（筛选紫）: #8B5CF6
- Deep Ink（深墨底）: #0B1020

规则：
- Logo（标志）允许有限的 Blue → Cyan → Violet（蓝 → 青 → 紫）渐变。
- UI（界面）本体不要把 Logo 渐变复制到每个按钮和卡片。
- 单色版本必须在纯黑 / 纯白下成立。

## Wordmark（品牌字标）
正式显示：**SiftAlpha**

要求：
- S 与 A 的识别清楚。
- 几何、干净、精密。
- 不附加醒目的 X。
- 如必须在技术场景显示系统名，可使用弱层级副标：
  - “SiftAlpha”
  - small caption（小型副标题）: “X System（X 系统）”
  但 Normal Mode（普通用户模式）不使用此组合。

## App Icon（应用图标）
- 深色圆角背景。
- 中央 S Mark（S 标志）占主视觉。
- S 的负空间保持充足，不让中心区域显得拥挤。
- Adaptive Icon（自适应图标）安全区内保留足够留白。
- Monochrome Icon（单色图标）只保留 S 的轮廓，不保留 >_。

## Brand Personality（品牌个性）
- SiftAlpha > X
- S clarity（S 的清晰度）> 技术暗号
- 可靠 > 炫酷
- 清晰 > 神秘
- 精密 > 复杂
- 普通用户可理解 > 开发者专属
