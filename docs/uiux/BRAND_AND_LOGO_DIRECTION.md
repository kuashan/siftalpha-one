# SiftAlpha X Brand + Logo Direction

## Brand Positioning
SiftAlpha X 不定义为泛化“科技风”。

正式品牌风格：

**Calm Precision Tech（克制精密科技）**

它表达的是：
复杂输入 → 筛选 / 收敛 → 执行 → 清晰结果。

品牌不是：
- 黑客终端
- 赛博朋克
- 夸张 AI 紫粉渐变
- 游戏化霓虹
- “未来科技”装饰堆砌

## Logo Concept — Sift Mark
推荐主方向：**Sift Mark（筛选标志）**

### Geometry
Logo 由 3–4 条输入路径进入一个中心“筛选节点”，路径在中心交叉形成一个抽象 X，并从另一侧形成一条清晰输出。

视觉上允许产生三层含义：
1. Sift（筛选 / 收敛）
2. X（SiftAlpha X）
3. Signal / Result（信号 / 结果）

可轻微暗示 S，但不能强迫观众阅读字母。

### Constraints
- App Icon（应用图标）在 24–32px 仍可识别
- 单色版本必须成立
- 不依赖细线和复杂粒子
- 不把字母 S、X、漏斗、图表四个图标机械拼接
- 不使用股票 K 线作为核心 Logo，避免把产品锁死为金融 App
- 不使用 Python logo / terminal prompt 作为品牌主体，避免把产品锁死为开发者工具

### Color
Primary:
- Sift Blue #4F46E5 light
- #7C8DFF dark

Accent:
- Sift Teal #0F766E light
- #35C6AE dark

Logo 优先用 1 个主色 + 中性底色。
Accent 只允许用于“筛选后输出”的最后一段或节点。

## Wordmark
显示：
**SiftAlpha X**

要求：
- 几何、干净、精确
- X 稍有独立识别，但不做夸张 superscript（上标）
- 不能做“游戏战队 / 加密交易所”视觉

## App Icon
建议：
- 深石墨 / 深海军蓝底
- 中央 Sift Mark
- 高对比单主色
- adaptive icon（自适应图标）安全区内保持足够留白
- monochrome icon（单色图标）必须同步设计

## Brand Personality
- 可靠 > 炫酷
- 清晰 > 神秘
- 精密 > 复杂
- 有未来感 > 科幻化
- 普通用户可理解 > 开发者专属
