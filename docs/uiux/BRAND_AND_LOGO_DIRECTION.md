# SiftAlpha X Brand + Logo Direction（品牌与标志方向）

## Current Authority（当前唯一方向）
**软件正式名称：SiftAlpha X。**

本轮不再重新发明 Logo（标志）几何。用户已经确认：设计稿中的 Logo（标志）应保持项目原始 Logo（标志）。

## Original Logo Lock（原始 Logo 锁定）
- App Icon（应用图标）：恢复仓库 r48d2（第 48 阶段 d2）基线中的原始 Logo（标志）资产。
- Brand Transition（品牌过渡）：直接使用同一原始 Logo（标志）。
- Home（首页）品牌位：使用同一原始 Logo（标志）。
- 不允许 Ribbon S（带状 S）、重绘 S、X 变体或其他近似图形替换原始 Logo。
- 允许动画的只有 opacity / scale / position（透明度 / 缩放 / 位置）和背景光效；Logo 本身几何不变。

## Wordmark（品牌字标）
正式显示：**SiftAlpha X**

Normal Mode（普通用户模式）所有主品牌名称与 Android app label（安卓应用名称）保持一致。

## Visual Fit（视觉对齐）
原始 Logo（标志）保持自身蓝 / 青 / 紫技术色。Normal Mode（普通用户模式）界面继续使用深蓝黑背景、蓝青紫层级光效，但 UI（界面）不能修改 Logo（标志）本身。

## UX Boundary（体验边界）
- 首页无 Bottom Navigation（底部导航）。
- 右上角仅 More（更多）。
- Project-first + State-driven + One Primary Action（项目优先 + 状态驱动 + 单一主操作）。
- Developer Mode（开发者模式）保持现状，不因品牌修正而改变。
